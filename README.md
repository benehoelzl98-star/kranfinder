# Kranfinder – App

Installierbare Web-App des Hölzl-Kran-Kranfinders: https://benehoelzl98-star.github.io/kranfinder/

Inhalte (Traglasttabellen, Flotte & Preise, Programmcode) sind mit dem App-Passwort verschlüsselt (AES-GCM, PBKDF2).
Diese Dateien werden automatisch erzeugt – nicht von Hand bearbeiten.
